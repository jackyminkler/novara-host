Novara hosts, M0 wireframes v2

August 19, 2026. Design source of truth for the M0 build, system A.1: field #F8F7FC, ink #241F3D, Poppins display, Instrument Sans interface, violet #4F3BC9 for meaning, gradient on primary actions only. Every screen maps to a PRD feature number. Mock content mirrors the seeded fictional partners; no real names appear. New in v2: host-entered mode with response provenance, inline edit states for tasks and run of show, the detailed create flow, the add-a-party picker with type profiles, the partner form, the recap edit state, and an M1 preview of the template editor. Guest links remain in spec but are an optional layer per the solo-first principle.
